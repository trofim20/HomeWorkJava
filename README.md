# Итоговое домашнее задание по Java

Консольное приложение для хранения и обработки пользователей. Выполнены базовый уровень и дополнительный уровень с собственной реализацией динамического массива

## Структура

```text
src/main/java/org/example/
  task1/
    Person.java        модель пользователя (имя, email, id)
    Menu.java          общее меню, ввод, файл, Stream API
    Main.java          запуск базового задания со стандартным ArrayList
  task2/
    CustomArrayList.java   собственный динамический массив
	CustomList.java		собственный интерфейс коллекции List
    Main.java          запуск уровня 2 с MyArrayList
src/main/resources/
  users.txt            пример входных данных
```

## Запуск

Для проверки уровня 1 запустите метод `main` в org.example.task1.Main. Для уровня 2 запустите `main` в org.example.task2.Main.

При запуске уровня 2 сначала демонстрируются `add`, `get`, `remove`, `size` и вывод списка

## Меню

1. Добавить пользователя вручную (имя, email, положительный целочисленный id).
2. Загрузить пользователей из файла.
3. Обработать коллекцию через Stream API: отобрать email, содержащие `mail`, преобразовать имя и email в верхний регистр через `map()`, отсортировать по имени и вывести результат.
0. Выйти.

Для добавления пользователей из файла выберите пункт 2 «Загрузить данные из файла» в консольном меню. Программа выведет приглашение `Введите путь к файлу:`. Путь нужно ввести непосредственно в консоли и нажать Enter.

Например, если программа запущена из корневой папки проекта, введите:

```text
src/main/resources/users.txt
```

Формат каждой строки файла:

```text
Anton anton@mail.ru 1
Polina polina@gmail.com 2
```

Поля разделяются одним пробелом. Чтение реализовано через `try-with-resources` с обработкой ошибок.

## Как работает CustomArrayList

`CustomArrayList<T>` — собственная реализация динамического массива с использованием Generics. Коллекция реализует интерфейс `CustomList<T>`, в котором объявлены основные методы работы с элементами.

### Хранение данных

- Для хранения элементов используется массив `Object[] mass` с начальной вместимостью 10 элементов.
- Переменная `size` хранит текущее количество элементов коллекции.
- При заполнении массива его вместимость автоматически увеличивается в 2 раза.

### Основные методы

- `customAdd(T value)` — добавляет элемент в конец массива.
- `customAdd(int index, T value)` — добавляет элемент по указанному индексу, сдвигая остальные элементы вправо.
- `customGet(int index)` — возвращает элемент по индексу с проверкой границ.
- `customSet(int index, T value)` — заменяет элемент по указанному индексу.
- `customRemove(T value)` — удаляет первое найденное совпадение по значению.
- `customRemoveAt(int index)` — удаляет элемент по индексу, сдвигая оставшиеся элементы влево.
- `customSize()` — возвращает текущее количество элементов коллекции.
- `customClear()` — очищает коллекцию и создаёт новый массив начальной вместимости.

### Вспомогательные методы

- `massIncrease()` — создаёт новый массив с удвоенной вместимостью и копирует в него существующие элементы.
- `checkIndex(int index)` — проверяет корректность индекса и выбрасывает `IndexOutOfBoundsException`, если индекс выходит за границы коллекции.
- `toString()` — формирует строковое представление содержимого коллекции.

### Особенности реализации

- Для хранения элементов не используется стандартный `ArrayList`.
- Реализован собственный интерфейс `CustomList<T>`.
- Поддерживается работа с различными типами данных благодаря Generics.
- Автоматическое расширение массива реализовано самостоятельно.
- При добавлении и удалении элементов по индексу выполняется сдвиг элементов массива.
- Предусмотрена обработка некорректных индексов.
- В классе `Main` продемонстрированы добавление, получение, изменение, удаление элементов, автоматическое расширение массива и очистка коллекции.
